# جيمي — مدرب ومتابعة تمرين وأكل وجسم

تطبيق للآيفون، **مجاني** و**بيشتغل من غير نت**. بيتثبت على الشاشة الرئيسية من Safari (PWA). كل الداتا على موبايلك بس، ومفيش أي سيرفر.

## فيه إيه

### التمرين
- **برنامج Full Body جاهز 3 أيام**، أو **ابني برنامجك** من المعالج حسب:
  - هدفك (تضخيم، قوة، ريكومب، تنشيف) وخبرتك.
  - عدد الأيام من 2 لـ 6 ومدة التمرين.
  - الأجهزة: جيم، دمبلز، أو وزن الجسم.
  - العضلات اللي عايز تركز عليها، والإصابات (ركبة، أسفل الظهر، كتف).
  - البرامج القديمة بتفضل محفوظة، وتبدّل بينها وقت ما تحب.
- **تسجيل كل مجموعة:** وزن، عدات، ثواني، متر، و**RPE**.
  - تايمر راحة بصوت، والشاشة متقفلش وإنت بتتمرن.
  - تمارين الناحية الواحدة بتتسجل شمال ويمين كل واحدة لوحدها.
- **تدرّج تلقائي:** مرحلة رجوع، وDouble Progression، وتخفيف لو الأداء وقع، وأسبوع خفيف (Deload) كل 7 أسابيع.
- **الجاهزية اليومية** (نوم، ضغط، ألم عضلات، تعب، إصابة) بتظبط الأوزان المقترحة، ومع كل تعديل سببه.
- **الأرقام القياسية:** بيظهرلك 🏆 لما تكسر رقمك، وفيه قايمة بكل أرقامك.
- **تحليل المدرب:** بتتقدّم، ثابت، ولا بتنزل؟ وليه، وإيه الخطوة الجاية.
- **خريطة العضلات** بعدد المجموعات الأسبوعية، و**إنجازات** وتحديات أسبوعية.
- **سجل التمارين:** تعدّل أي مجموعة قديمة، وتغيّر اسم أي تمرين.
- **صور توضيحية** لـ 89 تمرين شغالة أوفلاين، وتقدر تربط **فيديو** من الجاليري بأي تمرين.

### الأكل
- السعرات والبروتين والكارب والدهون محسوبة من الـ InBody أو الطول والوزن، حسب هدفك.
- تسجيل الوجبات من **67 أكلة مصرية وعامة**، أو أكلاتك انت، أو إضافة سريعة. وكمان المياه والمكملات.
- **تقرير أسبوعي:** فائض مناسب للتضخيم ولا لأ، و**تعديل السعرات حسب وزنك الفعلي**.
- **ميزانية يومية:** أرخص مصادر بروتين، واقتراحات تكمّل بيها البروتين في حدود ميزانيتك.

### الجسم
- **نظرة عامة:** الوزن واتجاهه، وBMI، ونسبة الدهون، والكتلة الخالية، وSMM.
- **أهداف** للوزن والدهون والوسط مع **توقّع تاريخ الوصول**.
- **InBody كامل** ومقاسات بالشريط، مع مقارنة الشمال واليمين.
- **صور التقدم** أمامي وجانبي وخلفي، ومقارنة بالسحب أو جنب بعض.

### الداتا
- **نسخة احتياطية** zip تحفظها على iCloud، وتسترجعها وقت ما تحب.
- **تصدير CSV/JSON** لـ Excel.
- **تقرير PDF:** من الطباعة، احفظ كـ PDF.
- **ملخص جاهز لـ ChatGPT:** انسخه والصقه.

## التثبيت على الآيفون

1. افتح لينك التطبيق من **Safari** (لازم Safari مش Chrome).
2. اضغط زرار المشاركة ⬆️، وبعدين **Add to Home Screen**، وبعدين Add.
3. افتح التطبيق من الأيقونة **وإنت متصل بالنت**.
4. من الإعدادات، استنى لحد ما يظهر "الشغل من غير نت: جاهز ✅".

> التطبيق اللي على الشاشة الرئيسية ليه تخزين منفصل عن Safari. لو مسحت الأيقونة، الداتا اللي جواها بتتمسح، فاعمل نسخة احتياطية الأول.

## النشر (Cloudflare Workers — مجاني)

متوصّل بالريبو من خلال Workers & Pages. أي push على فرع الإنتاج بيبني وينشر لوحده.

- الإعدادات في `wrangler.jsonc`: الملفات الثابتة من `dist/`.
- Build command: `npm run build`
- Deploy command: `npx wrangler deploy`

## للمطوّر

```bash
npm install
npm run dev        # سيرفر تطوير
npm test           # اختبارات المنطق وقاعدة البيانات (Vitest)
npm run build      # بناء نسخة الإنتاج في dist/
npm run e2e        # اختبارات المتصفح (Playwright، مقاس iPhone 13)
npm run check      # كل اللي فوق مع بعض
npm run catalog    # إعادة توليد كتالوج التمارين والصور من free-exercise-db
```

| المسار | الوظيفة |
|---|---|
| `src/domain/` | منطق بحت مستقل عن الواجهة: التدرّج، الجاهزية، الأرقام القياسية، التحليل، الإنجازات، بناء البرنامج، الجسم، التغذية، التصدير |
| `src/db/` | Dexie (IndexedDB): الجداول، العمليات، النسخ الاحتياطي (zip) |
| `src/data/` | كتالوج التمارين والأكل (بالعربي) والبرنامج الافتراضي |
| `src/lib/` | hooks وأدوات للواجهة (الأوفلاين، التصدير، الصور...) |
| `src/screens/` | الشاشات |
| `src/ui/` | مكونات مشتركة (الرسوم، الخريطة، التايمر...) |
| `docs/superpowers/` | المواصفات وخطط التنفيذ |

صور وبيانات التمارين من [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (Public Domain / Unlicense). قيم الأكل تقريبية.
