# جيمي — متابعة التمرين وقياسات InBody

تطبيق للآيفون، **مجاني** و**بيشتغل من غير نت**. بيتثبت على الشاشة الرئيسية من Safari (PWA).

## فيه إيه

- **برنامج Full Body جاهز 3 أيام** (A / B / C).
  - كل يوم: إحماء وتعديل وضع الظهر ← تمارين أساسية ← ساعد وقبضة وصوابع وبطن ← كارديو.
  - تمارين الرجل الواحدة بتتسجل **شمال ويمين كل واحدة لوحدها**.
- **تسجيل كل مجموعة:** وزن، عدات، ثواني، أو متر، وتايمر راحة بصوت، والشاشة متقفلش وإنت بتتمرن.
- **تدرّج تلقائي (Double Progression):**
  - أول أسبوعين مرحلة رجوع (مجموعتين بس).
  - بعد كده يقولك تزوّد الوزن إمتى وتخفّضه إمتى.
  - كل 7 أسابيع أسبوع خفيف (Deload).
- **صور توضيحية لكل تمرين** شغالة أوفلاين، وتقدر تربط **فيديو من الجاليري** بأي تمرين.
- **InBody كامل:** وزن، SMM، دهون (كيلو ونسبة)، دهون حشوية، BMR، مياه، ECW، والتحليل لكل جزء في الجسم.
  - رسوم بيانية للتطور، ومقارنة الرجل/الدراع الشمال باليمين.
- **مقاسات بالشريط:** ساعد، دراع، فخد (شمال ويمين)، وسط... إلخ.
- **محرر برنامج:** تعدّل المجموعات والعدات والراحة، تبدّل تمرين، تضيف أو تشيل، وتعمل سوبر سيت.
- **نسخة احتياطية:** ملف zip بتحفظه على iCloud، وتقدر ترجّعه في أي وقت.

> البيانات متخزنة **على الموبايل بس**، ومفيش أي سيرفر. اعمل نسخة احتياطية كل أسبوعين.

## التثبيت على الآيفون

1. افتح لينك التطبيق من **Safari** (لازم Safari مش Chrome).
2. اضغط زرار المشاركة ⬆️ ← **Add to Home Screen** ← Add.
3. افتح التطبيق من الأيقونة.
4. من **الإعدادات** فعّل "التخزين الدائم".

بعد أول فتحة، التطبيق بيشتغل من غير نت خالص.

## الرفع على Cloudflare Pages (مجاني، مرة واحدة)

الريبو Private، فـ GitHub Pages المجاني مش هينفع. Cloudflare Pages بيشتغل مع الريبوهات الـ Private مجانًا:

1. اعمل حساب مجاني على <https://dash.cloudflare.com>.
2. **Workers & Pages** ← **Create** ← **Pages** ← **Connect to Git**.
3. اربط حساب GitHub واختار الريبو `ELSYYAAD_PHONE`.
4. الإعدادات:
   - **Production branch:** الفرع اللي فيه الكود (مثلًا `main` بعد الدمج).
   - **Framework preset:** `None`
   - **Build command:** `npm run build`
   - **Build output directory:** `dist`
5. **Save and Deploy**. هتاخد لينك زي `https://elsyyaad-phone.pages.dev`.

بعد كده أي push على الفرع ده بيحدّث التطبيق لوحده، والتطبيق على الموبايل بيتحدث تلقائيًا أول ما يفتح وهو متصل بالنت.

## للمطوّر

```bash
npm install
npm run dev        # سيرفر تطوير
npm test           # اختبارات المنطق وقاعدة البيانات (Vitest)
npm run build      # بناء نسخة الإنتاج في dist/
npm run e2e        # اختبارات المتصفح (Playwright، مقاس iPhone 13)
npm run check      # كل اللي فوق مع بعض
npm run catalog    # إعادة توليد كتالوج التمارين والصور من free-exercise-db
```

| المسار | الوظيفة |
|---|---|
| `src/domain/` | منطق مستقل عن الواجهة: التناوب، التدرّج، الإحصائيات، تعديل البرنامج، التحقق من النسخة الاحتياطية |
| `src/db/` | Dexie (IndexedDB): الجداول، الـ seed، العمليات، النسخ الاحتياطي (zip) |
| `src/data/` | كتالوج التمارين (أسماء ونصايح بالعربي) والبرنامج الافتراضي |
| `src/screens/` | الشاشات |
| `src/ui/` | مكونات مشتركة (الرسم البياني، تايمر الراحة، عرض التمرين...) |
| `docs/superpowers/` | الـ spec وخطة التنفيذ |

صور وبيانات التمارين من [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (Public Domain / Unlicense).
