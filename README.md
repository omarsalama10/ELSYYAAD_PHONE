# ELSYYAAD Life OS — نظام تشغيل حياتك

تطبيق للآيفون (PWA) **مجاني** و**بيشتغل من غير نت**، بالعربي من اليمين للشمال. بيدير يومك ومشاريعك وأهدافك وعاداتك، وفيه موديول الصحة والجيم (جيمي) كقسم مستقل.

> كل البيانات على الموبايل بس، ومفيش سيرفر. التخطيط بـ Claude بيحصل **برا التطبيق**: التطبيق بيصدّر حالتك الحقيقية، وClaude يرجّعلك ملف خطة تراجعه وتعتمده.

## فيه إيه

- **مدير اليوم:** المهمة الحالية والتالية تلقائيًا، أهم 3 أولويات (بنجمة يدوية)، الوقت المخطط/المتبقي/الفاضي/الالتزامات، تقدم اليوم والأسبوع، جدول زمني تسحب فيه المهام لوقت جديد، المتأخر والمعرض للخطر وغير المجدول، ابدأ/وقّف/خلصت بضغطة، وضع تركيز يخفي كل حاجة غير المهمة الحالية، بحث شامل، وإضافة سريعة بسطر واحد (`مراجعة الكود 45د !4 #المشروع @بكرة 14:00`).
- **محرك جدولة محلي:** يفرق بين الالتزامات الثابتة والمهام المرنة، يحسب السعة الفعلية ويسيب هامش طوارئ، أولوية بعوامل واضحة (أهمية، قرب الموعد، بتعطّل غيرها، اتأجلت)، اعتماديات، تقسيم المهام الكبيرة لجلسات، حماية المواعيد النهائية، تنبيه الحمل الزائد، إعادة جدولة بتعرض الفرق قبل الاعتماد، و«ماذا لو؟» (ضاع وقت، الجيم اتلغى، 4 ساعات زيادة لمشروع…). كل ده من غير نت.
- **المهام:** وصف وملاحظات وروابط ومرفقات (صور وملفات)، مشروع ومرحلة وهدف، أولوية وموعد وتاريخ بدء، مدة متوقعة (مؤكدة/تقديرية) وفعلية، نسبة إنجاز، قائمة تحقق، اعتماديات، تكرار يومي/أسبوعي/شهري، سجل كامل للتغييرات والتأجيلات وأسبابها، تعليقات، قوالب، فلاتر، تحديد متعدد وتعديل جماعي، سلة محذوفات، واقتراح مدة من تاريخ مهام مشابهة.
- **المشاريع:** مراحل رئيسية وفرعية، Kanban وقائمة وTimeline، تقدم محسوب (وزن متساوٍ أو بالمدة أو مخصص)، المتوقع مقابل المستهدف، اللي معطّل المشروع، سجل قرارات ومخاطر ومشاكل، قوالب مشاريع، أرشفة، وتقرير حالة لـ Claude.
- **الأهداف:** نتيجة ومعيار نجاح وقياس (مهام، رقم، مراحل)، مقارنة بالمتوقع حسب الوقت، إسقاط تاريخ الإنجاز، اقتراح تقليل النطاق أو مد الموعد، وسجل لكل تغيير بسببه.
- **التذكير والمتابعة:** 3 مستويات (هادئة/متوازنة/حازمة)، تذكير قبل وعند البداية، متابعة بعد الانتهاء (اكتملت؟ جزئيًا؟ تتأجل؟)، ملخص صباحي ومراجعة مساء، فترات هدوء، إيقاف أنواع أو تصنيفات، وسجل لكل تذكير وحالته.
- **التركيز والوقت:** جلسات تركيز واستراحة مربوطة بمهمة، إيقاف واستكمال، تسجيل المقاطعات، الوقت الفعلي مقابل المقدر.
- **العادات والإيقاع:** يومي/أيام محددة/عدد مرات في الأسبوع، سلاسل بقاعدة «متفوّتش يومين ورا بعض»، أيام معذور، تقييم اختياري للطاقة والتركيز وسبب انخفاض الإنجاز، وأيام راحة.
- **التحليلات:** معدل التنفيذ، الالتزام بالمواعيد، دقة التقدير، سرعة الإنجاز، ثبات الخطة، توازن الحمل — كل مؤشر بتعريفه وبسطه ومقامه، والوقت حسب المشروع والتصنيف وساعات اليوم، المخطط مقابل الفعلي، وتصدير CSV/JSON.
- **Claude والبيانات:** تصدير الحالة (Markdown/JSON) مع تعليمات صيغة ملف الخطة، استيراد ملف خطة مع مراجعة كل تغيير، Snapshots تلقائية قبل الاستيراد والترقيات، والرجوع لأي نسخة.
- **الصحة والجيم:** برنامج Full Body، تسجيل المجموعات، تدرّج تلقائي، InBody ومقاسات، صور التمارين أوفلاين (زي الإصدار السابق) من «المزيد ← الصحة والجيم».

### حدود الآيفون (بصراحة)

iOS مش بيسمح لتطبيقات الويب تشتغل في الخلفية. التذكيرات بتوصل والتطبيق مفتوح أو لسه في الخلفية، واللي يفوت والتطبيق مقفول بيظهر في «التنبيهات» أول ما تفتح. **للتنبيه المضمون:** من «الخطة» اضغط «📅 للتقويم» واعمل Add All في تقويم الآيفون — التنبيهات هتشتغل حتى والتطبيق مقفول ومن غير نت.

**النسخة الاحتياطية:** من الإعدادات اعمل نسخة zip كل أسبوعين واحفظها على iCloud Drive — بتشمل Life OS والجيم والمرفقات.

التفاصيل الفنية: [`docs/lifeos/ARCHITECTURE.md`](docs/lifeos/ARCHITECTURE.md) • صيغة ملف الخطة: [`docs/lifeos/PLAN_FILE.md`](docs/lifeos/PLAN_FILE.md)

## التثبيت على الآيفون

1. افتح لينك التطبيق من **Safari** (لازم Safari مش Chrome).
2. اضغط زرار المشاركة ⬆️ ← **Add to Home Screen** ← Add.
3. افتح التطبيق من الأيقونة.
4. من **الإعدادات** فعّل "التخزين الدائم".
5. من **الإعدادات ← التخطيط والتذكير** فعّل الإشعارات وحدد ساعات يومك.

بعد أول فتحة، التطبيق بيشتغل من غير نت خالص.

## الرفع على Cloudflare Pages (مجاني، مرة واحدة)

الريبو Private، فـ GitHub Pages المجاني مش هينفع. Cloudflare Pages بيشتغل مع الريبوهات الـ Private مجانًا:

1. اعمل حساب مجاني على <https://dash.cloudflare.com>.
2. **Workers & Pages** ← **Create** ← **Pages** ← **Connect to Git**.
3. اربط حساب GitHub واختار الريبو `ELSYYAAD_PHONE`.
4. الإعدادات:
   - **Production branch:** الفرع اللي فيه الكود (مثلًا `main` بعد الدمج).
   - **Framework preset:** `None`
   - **Build command:** `npm run build`
   - **Build output directory:** `dist`
5. **Save and Deploy**. هتاخد لينك زي `https://elsyyaad-phone.pages.dev`.

بعد كده أي push على الفرع ده بيحدّث التطبيق لوحده، والتطبيق على الموبايل بيتحدث تلقائيًا أول ما يفتح وهو متصل بالنت.

## للمطوّر

```bash
npm install
npm run dev        # سيرفر تطوير
npm test           # اختبارات المنطق وقاعدة البيانات (Vitest)
npm run build      # بناء نسخة الإنتاج في dist/
npm run e2e        # اختبارات المتصفح (Playwright، مقاس iPhone 13)
npm run check      # كل اللي فوق مع بعض
npm run catalog    # إعادة توليد كتالوج التمارين والصور من free-exercise-db
```

| المسار | الوظيفة |
|---|---|
| `src/life/domain/` | منطق Life OS المستقل عن الواجهة: الجدولة، الأولوية، التقدم، العادات، التحليلات، التذكير، ملفات الخطة، التصدير |
| `src/life/db/` | قاعدة بيانات Life OS (Dexie) والعمليات والـ snapshots |
| `src/life/screens/`, `src/life/ui/` | شاشات ومكونات Life OS |
| `src/domain/` | منطق الجيم: التناوب، التدرّج، الإحصائيات، تعديل البرنامج، التحقق من النسخة الاحتياطية |
| `src/db/` | Dexie (IndexedDB): الجداول، الـ seed، العمليات، النسخ الاحتياطي (zip) |
| `src/data/` | كتالوج التمارين (أسماء ونصايح بالعربي) والبرنامج الافتراضي |
| `src/screens/` | الشاشات |
| `src/ui/` | مكونات مشتركة (الرسم البياني، تايمر الراحة، عرض التمرين...) |
| `docs/lifeos/` | معمارية Life OS وصيغة ملف الخطة |
| `docs/superpowers/` | spec وخطة الجيم |

صور وبيانات التمارين من [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (Public Domain / Unlicense).
